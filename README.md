# Crimson County — RedM Roleplay

A cinematic, mobile-friendly static website for Crimson County. Ready for free hosting on GitHub Pages.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com) and create a new **public** repository called `crimson-county` (or another name).
2. Upload **all files and the `assets` folder from this ZIP to the root of the repository**, not into a nested folder. The `index.html` file must be at the top level.
3. Commit the files to the `main` branch.
4. In your repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/ (root)`, then click **Save**.
6. Once deployment finishes, visit `https://YOUR-USERNAME.github.io/crimson-county/` (replace `YOUR-USERNAME` with your GitHub username, and the final path with your repository name).

Publishing may take a few minutes. Future commits to `main` automatically update the site.

## Edit the site

- `index.html` — text, navigation, sections and external links
- `style.css` — colours, typography, layout and mobile styling
- `script.js` — interactive mobile menu and join button
- `assets/crimson-banner.webp` — Crimson County artwork

Discord invitation currently used: https://discord.gg/crimsoncountyrp

The site uses Google Fonts (Rye and Roboto Slab), which require an internet connection. No server-side software or build tools are needed.

## Optional custom domain

GitHub Pages supports custom domains. Configure the domain under **Settings → Pages** and follow GitHub's DNS instructions. Enable **Enforce HTTPS** once available.

## Note

GitHub Pages hosts static sites. If you later add logins, application submissions, or database-driven features, those will require additional services.
