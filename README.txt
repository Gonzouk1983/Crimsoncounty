CRIMSON COUNTY WEBSITE

HOW TO RUN:
1. Extract the ZIP file.
2. Open the crimson-county folder.
3. Double-click index.html to view the website in your browser.
4. For local development, you can also open the folder in VS Code and use Live Server.

FILES:
index.html — Website content and sections
style.css — Colours, fonts and mobile design
script.js — Mobile menu and Join button
assets/crimson-banner.webp — Your supplied Crimson County artwork

DISCORD LINK (NOW CONFIGURED):
The current Discord invite is https://discord.gg/crimsoncountyrp
To change it, edit DISCORD_INVITE_URL in script.js and the Discord links in index.html.

The main Join button will then open your Discord invite.
The other Join links on the page scroll down to this button.

Fonts are loaded from Google Fonts, so internet is needed for the exact Rye and Roboto Slab fonts. The site still works offline using fallback fonts.
